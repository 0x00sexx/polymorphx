Core Capabilities

Enterprise-grade obfuscation techniques designed to evade modern EDR/AV solutions

Polymorphic Engine

Mandatory polymorphic decoder stub that generates unique signatures per compilation. Randomized variable names, instruction ordering, and junk code insertion ensure no two builds are identical.

🔐

Multi-Layer Encryption

ChaCha20 stream cipher with obfuscated constants, combined with polymorphic encoding layers (XOR/ADD/SUB/ROT). Randomized hash seeds (MurmurHash3) provide unique API signatures.

🛡️

EDR Evasion

Advanced NTDLL unhooking capabilities defeat user-mode EDR hooks. Supports both per-function unhooking (Perun's method) and full .text section replacement from clean disk copy.

🔍

Anti-Debugging Suite

Comprehensive debugging detection: IsDebuggerPresent, PEB checks, NtQueryInformationProcess, hardware breakpoint detection (DR0-DR3), timing analysis, and parent process verification.

⚡

No-RWX Injection

Memory-safe injection technique that never allocates RWX pages simultaneously. Combined with SecureZeroMemory for sensitive data cleanup and PEB walking for dynamic API resolution.

📊

Low-Entropy Storage

Auto-selected storage encoding (UUID/IPv4/Words) reduces entropy in .rdata section to evade statistical analysis. Each method provides ~3-5 bits/byte effective entropy.

Technical Specifications

Advanced implementation details and evasion techniques

API Hashing
MurmurHash3_x86_32 implementation with randomized seeds per compilation. Supports kernel32.dll and ntdll.dll function resolution.
PEB Walking
Dynamic API resolution via Process Environment Block traversal. Eliminates static import dependencies for stealth.
DLL Unhooking
Per-function unhooking restores individual Nt/Zw syscall stubs. Full .text unhooking replaces entire hooked NTDLL section from disk.
ChaCha20 Encryption
256-bit key stream cipher with 96-bit nonce. Constant obfuscation prevents static signature detection.
Polymorphic Decoding
Four encoding methods: XOR, ADD, SUB, ROT (rotation-based). Variable key sizes (4/8/16 bytes) with randomized loop constructs.
Anti-Analysis
Hardware breakpoint detection via debug registers. Timing-based analysis detection with RDTSC/GetTickCount64.
Process Verification
Parent process name checks detect common debuggers (x64dbg, WinDbg, IDA, OllyDbg). Silent exit on detection.
Direct PE Generation
Automated compilation to Windows PE executable via MinGW. Optimization levels configurable (O0-O3, Os).
